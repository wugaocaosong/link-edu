# 数据、信息与知识 · 典型误解对照表

> 临客整理 · 训练用对照表，非官方资料。用于微格试讲练习中的"预判学生误解 → 当堂纠错与追问"。

## 误解一：数据和信息是一回事

- **学生说法**："38.5 就是信息啊，不就是个数据嘛。"
- **纠错要点**：数据是原始记录，信息是解释后的含义；没解释之前只是数。
- **追问示例**："如果我只写 38.5，不告诉你在哪、什么单位，你知道它想说什么吗？"
- **当堂处理**：让学生补一句解释，把数据"变成"信息，当场体会加工这一步。

## 误解二：信息越多越有用

- **学生说法**："搜到 2000 条结果，肯定比 20 条强。"
- **纠错要点**：信息有真伪与时效，无关信息反而干扰判断；有价值才叫有信息量。
- **追问示例**："查发烧怎么办，广告页和医院指南，哪份对 solves 问题更有用？"
- **当堂处理**：给两段材料让学生选，说出取舍理由。

## 误解三：知识就是把信息背下来

- **学生说法**："我把网上的说法都记住，就是知识了。"
- **纠错要点**：知识是归纳出的**规律与判断**，能用来解释新情况；只背句子不等于获得知识。
- **追问示例**："记住『高热要就医』之后，弟弟半夜发烧你敢用这条判断吗？为什么敢？"
- **当堂处理**：让学生用归纳出的规律解释一个**没见过**的新例子，验证是否真懂。

## 误解四：链条可以倒过来

- **学生说法**："先有知识，再变成信息，再变成数据。"
- **纠错要点**：教学主线是"数据 → 信息 → 知识"的加工方向；倒序是记录与传播的过程，不是认知加工方向。
- **追问示例**："我们这节课是从一堆数开始，还是从一条规律开始的？"
- **当堂处理**：用板书上的流程图回扣，让学生指着箭头复述一遍。

## 使用建议

1. 试讲练习时，可任选 1–2 条误解，设计 30 秒的纠错 + 追问片段。
2. 追问后停 3 秒再接话，给学生真的思考时间（演法见《无生试讲互动话术库》）。
3. 纠错句式：先复述学生的话 → 指出卡点 → 抛回问题，不直接报答案。
