# 数据、信息与知识 · 核心知识卡

> **用途**：高中信息技术微格实训备课参考（临客自编整理）。
> **性质**：训练用摘要，**不是**国家课程标准全文，也**不是**教资面试统一评分条文。
> **公开延伸阅读**：[国家中小学智慧教育平台｜高中信息技术](https://basic.smartedu.cn/)（仅作入口索引，不转载教材全文）。

## 1. 数据

- 数据是对客观事物的**原始记录**，如数字、文字、图像、声音、视频。
- 数据本身没有语义：`38.5` 只是一个数，脱离上下文不知道它是体温、股价还是降水量。
- 课堂可先出示一组"裸数据"，让学生猜含义，制造认知冲突。

## 2. 信息

- 信息是数据经过**加工、解释后有了含义**的内容："昨夜体温 38.5℃，比正常偏高"——这才叫信息。
- 常用特征：载体依附性、价值性、时效性、可共享性（训练时点到即可，不必背全表）。
- 追问句示例："同一个数字 38.5，在体检单上和在股市行情里，含义一样吗？"

## 3. 知识

- 知识是对信息**归纳、抽象出的规律与判断**："持续高热提示可能感染，应及时就医"。
- 三者链条：**数据 →（加工/解释）→ 信息 →（归纳/验证）→ 知识**，箭头方向不能倒。
- 学生能举例说完整链条，才算真懂，而不是背三个名词。

## 4. 课堂表达建议（训练用）

1. 先给原始数据 → 再解释成信息 → 最后归纳成知识，例子要用**同一个**贯穿。
2. 学生把三者混说时，回到"有没有含义、有没有规律"两个判据上，而不是只纠正用词。
3. 小结回扣一句："数据是原料，信息是加工后的含义，知识是从中提炼出的规律。"
