## 这个包拿来干什么

面试抽到高中信息技术必修一的课题，最缺的是「这一课到底讲什么」——这个包就是干这个的。14 份教案按教材目录排好了，抽到哪一课，翻对应那一份就知道知识结构、重难点在哪儿，再按自己的话改成试讲稿。

## 里面有什么

**第 1 章 数据与计算**
- 1.1 数据、信息与知识
- 1.2 数字化与编码
- 1.3 数据科学与大数据

**第 2 章 算法与程序实现**
- 2.1 解决问题的一般过程和用计算机解决问题
- 2.2 算法的概念及描述
- 2.3 程序设计基本知识
- 2.4 常见算法的程序实现

**第 3 章 数据处理与应用**
- 3.1 数据处理的一般过程
- 3.2 数据采集与整理
- 3.3 数据分析与可视化
- 3.4 数据分析报告与应用

**第 4 章 人工智能**
- 4.1 认识人工智能
- 4.2 利用智能工具解决问题
- 4.3 人工智能的应用与影响

**附**：高中必修一《数据与计算》电子课本（人教中图版，PDF）

## 怎么用

1. 先定课题，从目录里挑对应那一份教案，通读一遍理清知识线；
2. 把教案里「教师活动」那部分翻成第一人称口播——教案是写给老师看的，试讲是说给学生听的，这一步不能省；
3. 教案里的教学目标和重难点可以留，但导入和例子最好换成自己的；
4. 电子课本用来核对教材原文表述，避免讲错概念。

## 注意

- 教案是备课材料，不是逐字稿。照读会很像念教案，评分老师一听就出来。
- 教材版本以人教中图版（2019）为准，抽题若来自其他版本，概念一致但章节编号可能不同。
