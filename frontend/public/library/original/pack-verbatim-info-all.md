> 来源：百度网盘公开分享资料，第三方整理。稿件版权归原作者所有，本站仅作面试备考参考，不用于商业传播。
> 共 34 份文件，319.3 MB。不需要解压：下面的清单每份文件都能直接点开查看或下载。

## 这个包拿来干什么

抽到信息技术课题，最缺的不是模板，是「这一课具体怎么说」。这个包就是干这个的：**先按课题找到对应的稿子，读一遍知道节奏和话术，再改写成自己的版本**。236 篇覆盖高中信息技术常考题目，基本不会抽到完全没见过的课。

## 怎么用

1. **先定课题范围**：翻【04】真题汇编，看自己那一场最可能抽到什么；
2. **找对应稿子**：单课用【02】二十篇或【07】五十五篇，整册用【01】上下册；
3. **别照背**：【03】上岸熊版是对照用的——看它怎么把题本要求翻译成课堂语言，然后用自己的话重写；
4. **答辩提前准备**：【03】里每课都附了答辩预设，读的时候顺手记下三个可能被追问的点。

## 注意

- **纯图版 PDF 的坑**：扫描图片，不能复制文字，也没法搜索关键词。想摘句子只能手打，或者用 OCR 工具转一遍。
- 稿子是别人写的，**语气、例子、学生姓名都带着别人的痕迹**。照读评分老师听得出来；至少把导入和例子换成自己的。
- 原包里的「【05】示范视频 + 知识点梳理」**视频部分没下**（体积大、非会员限速跑不完），只收了同目录下 3 份知识梳理课件 PDF，这个包不含视频。
- 【02】结构化卢姨 800 题（205MB）、试题 200 题里的真人示范视频也没下完，不在此包内。
