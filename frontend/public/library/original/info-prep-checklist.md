# 信息技术课备课与教具清单

> 临客整理 · 训练用清单，非官方规定。备《数据、信息与知识》时逐项打勾。

## 课题信息

- 课题：数据、信息与知识（高中信息技术必修一第 1 节）
- 课型：概念课 · 无需机房
- 目标时长：微格 8–10 分钟 / 完整 40 分钟（本清单按微格写）

## 教具与材料

- [ ] 课件一页：只写 `38.5`，字号撑满（导入悬念用）
- [ ] 板书笔：三色（主线一色、关键词一色、判断区一色）
- [ ] 备选实例一个：步数统计 / 电费单（万一 38.5 引不来猜测，立刻换例）
- [ ] 计时器：手机倒计时，导入超 90 秒就切

## 情境与导入

- [ ] 情境一句话能说清：一个孤零零的数，猜不出含义
- [ ] 30 秒内落到认知冲突：光有数 ≠ 知道它在说什么
- [ ] 预想 2–3 种学生猜测，接法各想一句（体温 / 气温 / 股价）

## 易错点预判

- [ ] 数据、信息混说 → 回到"有没有含义"判据
- [ ] 背诵 ≠ 知识 → 回到"能不能解释新情况"判据
- [ ] 链条方向说反 → 板书箭头回扣（详见《典型误解对照表》）

## 10 分钟时间切分

| 环节 | 时长 | 自检点 |
|------|------|--------|
| 导入 | 1′ | 30 秒内出现悬念 |
| 数据 | 1.5′ | 板书"原始记录" |
| 信息 | 2.5′ | 追问股市 38.5 |
| 知识 | 2.5′ | 箭头方向不倒 |
| 巩固 | 1.5′ | 判断题停 3 秒 |
| 小结作业 | 1′ | 作业三行以内 |

## 考前三问

1. 这节课**唯一的**主线例子是什么？（必须是同一个：38.5 贯穿全课）
2. 学生最容易卡在哪？（数据/信息不分；链条方向）
3. 被问到课标/教材没写的说法时怎么接？（回到两个判据，不硬编）
