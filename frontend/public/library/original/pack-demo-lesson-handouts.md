## 这个包拿来干什么

试讲抽到一道题本，第一步是把题本拆对：这节课的知识主线是什么、重点难点在哪、10 分钟里讲哪一段。这 24 份讲义每份都在做同一件事——把一道真实高中信息技术题本从审题到教学设计完整拆开讲。自己备完课再对照，看自己漏了什么、拆歪了没有。

## 里面有什么

**试讲 15 篇 · 题本分析**（一题一份）
按传输介质分类 / 搜索技巧 / 网上交流的安全 / 逐帧动画的制作 / 网站的基本概念 / 信息的一般特征 / IP 地址的类型 / 插入图片 / 修剪图像 / SQL 的数据更新 / 斐波那契的兔子问题 / 网络中的连接设备 / 使用数据库应用系统 / 用计算机解决问题的一般步骤 / 图像的基本概念

**出境 5 篇 · 课件**
域名的一般知识 / 逻辑运算 / 添加网页元素 / 搜索引擎 / 信息与数据

**系统课讲义 4 份**
- 高中信息技术·试讲（方法总纲）
- 示范点评班 + 题本梳理班讲义
- 题本梳理（高中信息技术）
- 高中信息技术·答辩

## 怎么用

1. 先读系统课的《试讲》总纲，知道题本分析的一般框架；
2. 抽一道真题（真题汇编合集里有），自己先备课写出教案；
3. 再翻开同课题的题本分析讲义对照：知识主线拆对没有、重难点定准没有、互动环节设计有没有漏；
4. 备考后期一天一份，保持「审题—拆解—设计」的手感。

## 注意

- 这批讲义是配套示范视频课程用的，视频本身没有入资源库（视频不收藏，是定好的规矩）。讲义单看也完整，不影响使用。
- 答辩讲义和《万能模板包》里的答辩六大原则重叠，二选一看就行。
