# 《认识几分之一》实验现场运行

## 登记与开场

1. 使用现有启动流程初始化数据库。已有实例通过 Alembic 升级至 `20261123_01`。在正式数据库操作前按现有流程备份。下列命令在 backend 目录运行，使用与应用相同的数据库环境。
2. 协调员确认 16 个不同账号都已加入实验机构，按 P01–P16 顺序准备私有 CSV，列为 `user_id,experience`，既有试讲经历用 0 或 1。姓名、联系方式及签署同意记录由协调员另行保管。分配只执行一次，在各经历层随机打乱、总量 8∶8，各组 A/B 顺序各四人。

```powershell
python -m flask --app app study allocate 机构数字编号 roster.csv
python -m flask --app app study roster 机构数字编号 coordinator-initial.json
```

3. 参与者登录后，由演绎厅的“实验场次”进入，或访问同源 `/study`。主持人另从协调员取得本场图卡与成人脚本。平台前测前隐藏组别。请事先核对摄像头、扬声器、双人收音和纸张取景，并确认浏览器可录制及导出视频。

正式登记前可执行 `python -m flask --app app study pilot 机构数字编号 试跑账号数字编号 --arm multimodal`，再用该账号走完四场。另一名非参试人员可用 `--arm transcript` 验证另一种平行脚本顺序。两个试跑位使用 QA 编号，独立于正式名册。

## 两次到场

| 场次 | 操作与核验 |
|---|---|
| 共同前测 | 真人应答。检查设备后开始计时，按实际发生时刻分别标记机会 1 和 2。5 分钟自动停止。回放核对音画，填写扮演者编号。遗漏、设备问题和提前结束须注明。 |
| 首轮试讲 | 在平台用折纸试讲 10 分钟。教师可点名、追问、点击邀请学生。录像与课堂事件分别留存。结束后先写独立自评和想回看的课堂时间，再领取本组报告、看录像，并记下本人的修订目标。 |
| 第二轮试讲 | 预约间隔 7 天，换用纸带和第二轮角色安排；两组采用相同轮换。实际间隔在协调员登记表中计算。 |
| 共同后测 | 完成第二轮反馈后收起报告和教案，打开独立测评，以另一套脚本施测。将独立片段号命名的盲评包混排后分别交给两名评分者。 |

盲评包包含视频和两次机会的空白评分表；核对视频中没有口头报姓名、组别或轮次。浏览器本机保存与服务器研究登记是两份资料。每场要实际打开导出的包，试听双方、检查画面和跳转，再复制到获准的研究存储。课堂、补测与中断分段分别保留。

## 协调员导出与异常处理

```powershell
python -m flask --app app study research-export 场次编号 research.json
python -m flask --app app study observe 场次编号 22000 audio_unclear "主持人听到杂音，不能确认理由是否清楚"
python -m flask --app app study roster 机构数字编号 coordinator-final.json
python -m flask --app app study repeat 场次编号 "设备中断；已接触第一张图卡"
```

研究导出含原分组、场次、轮换安排、实际证据、时间锚点、自评、已发放报告和目标；个人研究包与盲评包分开交接。参与者在反馈页可导出本机录像及分段时间表。课堂事件使用含暂停的墙钟毫秒，只有落入某个录像分段的锚点才可跳转。研究导出保留全部已启动学生回复的命运；脚本步骤指当时要求学生表达的线索，实际措辞仍须核对原话。

训练场次的研究导出另附 `capture_summary`。先看有多少条已完成回复同时记录了播放起止，再按 `completed_without_onset` 中的回复编号核查缺项。起点缺失时保留空值，避免把生成时间当成播放时间。`motion_samples` 中的分子和分母分别为可观察样本数与采样总数。纸面是否清晰、双方能否听清仍须主持人回放核验。这份摘要仅供协调员核查采集质量。

同一次暂停可以恢复。需正式重做时，协调员对最近场次登记原因，新建关联补测；旧记录保留。缺席或退出时保留原分配和已完成资料，按已签署说明处理，不为缺席者创建课堂。盲评包、自评与报告只用研究设备和指定存储交接，禁止将真实实验导出放入仓库。

评课队友的联调入口及发放格式见 [AI 评课模块交接报告](./AI评课模块交接报告.md)。
