# 《分数的初步认识》AI 评课模块交接报告

## 交付边界

本次实验有两轮 10 分钟虚拟学生训练。两组参加相同训练、提交独立自评、阅读各自的形成性反馈并回看录像。技术部已实现按场次分组的证据封装、报告发放、原文保存和修订目标登记。评课负责人接手模型生成、提示模板冻结、输出核验与实际报告发放。5 分钟真人测评由两名评分者分别看录像评分。

## 从哪里取得输入

在 backend 目录使用部署环境的 Python 运行以下命令。协调员用登记表取得场次编号。导出目录由研究团队保管。

```powershell
python -m flask --app app study packet 12 packet-12.json
```

只有该场训练结束且参与者提交了自评，才会有输入包。外层含场次编号、版本和输入 SHA-256。**只有 `input` 发送给评课模型**。参与者编号、组别名、独立自评、首轮目标、盲评成绩、原始录像和研究导出文件均不进入模型。普通课堂的自动评课已对实验场次停用。

| 输入 | 内容与使用方法 |
|---|---|
| 两组共用的 `transcript` | 按发生顺序排列的轮次号、说话人和定稿原话。学生发言须匹配同一回复的完整播放确认。被打断的回复可能已经播出开头，当前版本保守排除整句，保留异常供研究人员核查。 |
| 多模态组的 `playback` | 学生回复与转写轮次的关联、客户端播放起点和终点回执所对应的课堂毫秒位置。缺失时间为 null。回执反映软件播放状态，现场听不清须另外登记。 |
| 多模态组的 `teacher_motion` | 动作样本覆盖、各模态状态计数、观察区间和参考事件。覆盖不足时只说明缺项；手形、方向或姿态需结合录像核实，不能据此认定教师指向哪一份纸、学生学会了什么。 |

随附的 [成对输入样例](./paired-inputs.json) 使用同一段合成事件生成，包含一次播完的学生回答、一次未播完的回答，以及缺失的动作。正式生成应直接读取实际场次文件。

## 生成与发放

冻结规格在 `backend/services/study_review.py`，两组共用，不按组别改写：

- 模型 `deepseek-v4-flash`。运行环境的对话模型不一致时，生成命令直接拒绝。
- 采样 `temperature=0`、`top_p=1`、关闭 thinking、`max_tokens=1200`、只返回 JSON。
- 量规 `fraction-formative-1`，模板 `fraction-narrative-1`。渲染后的报告为 280–900 字。
- 教学上下文须按参与者登记的年级和课时目标提供，两组完全一致；旧版“认识几分之一”固定提示不适用于扩展后的主题。是否保留共同学科上下文，须在正式实验提示冻结前统一决定。

1. 实验动作和播放线索只通过证据包提供。转写组的用户消息只有 `transcript`。
2. 报告选取一至两个片段。先引用转写轮次和学生原话，再写教师随后做了什么，最后给一项下次可以尝试的具体做法。若证据止于学生回答，明确写明后续教师行为缺失。报告中分开呈现可观察事实和建议。语义判断须能回溯原话，引用的时间与动作须出现在本场输入。
3. 教师定稿不足 2 段或不足 80 字时不调用模型。识别探针失败时同样不能把未确认文本补进证据包。

```powershell
python -m flask --app app study speech-probe
python -m flask --app app study generate 12 report-12.json
python -m flask --app app study issue 12 report-12.json
```

`study generate` 只把已封存证据包作为用户消息，并把实际请求写入报告文件。相同输入、模型、量规和模板的结果缓存在 `backend/instance/study-review-cache/`。命令不自动发放。`study issue` 在写入前核对请求、引用、未播完理由和篇幅；核对失败不改已发放原文。相同内容可以重试。更正或生成失败作为独立研究日志留存。

4. 参与者在实验场次点击“刷新报告”，阅读原文后定位自评片段或某一师生轮次。首轮由本人填写修订目标；次轮可回看此前目标。模型服务失败时向主持人登记，保留输入包和原分组。

## 联调验收

- 将同一事件序列分别构造成两种输入，共同转写逐轮完全一致。检查转写组的实际模型请求，新的系统提示、历史会话、工具检索和缓存均不得带入隐含时长或动作。缓存按完整输入及模型和模板版本区分。
- 学生说“有两块”且教师已经听到时，建议可以围绕怎样确认两块等大展开。若学生的理由未播完，报告不得指责教师忽略了该理由。静音、播放失败、重复回执和中断均须测试。
- 回放核实每条引用，记录输入摘要、模型与量规版本、实际发放报告、发放时间和异常。两组报告应使用相同结构与篇幅；由同一位检查者检查是否引入了额外辅导。
- 主要结局由共同测评计算。两名评分者按项目《AI评课整体量规》的4个一级指标、12个二级指标及既定权重独立评分。各项保留两次机会的原始分、证据位置与暂不评分原因。原量规所需的1、3、5级行为锚点及权重汇总/缺失处理算法须在正式测评前共同冻结。不得使用旧版任务专用四维或4–20分总分替代。


## 与课堂总量规及实验主题的衔接

共同测评采用项目《AI评课整体量规》4个一级指标、12个二级指标及其权重，实验方案不再使用单独设计的四维主要评分。训练报告仍按研究条件使用最终转写或转写加播放/动作证据，形成有原文和时间位置支持的形成性反馈；它的观察叙述可以聚焦回应性教学，但不得把训练报告的观察主题替代共同测评总量规。

本轮教学主题调整为小学数学“分数的初步认识”。参与者自行登记一节课内的目标和内容，两轮目标范围与难度尽量可比。共同测评的A/B材料不指定只能讲“认识几分之一”，由团队按12项量规审定并冻结。正式评分前检查12项在共同测评中的可观察覆盖。录像完整但未出现相关行为，与材料或录像缺失造成暂不评分须分开记录。量规、评分锚点、脚本、权重算法的任何变更都要在正式样本前冻结并留版本。
