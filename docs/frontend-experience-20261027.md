# 前端体验优化 · 2026-10-27

本轮启动本地前后端，在现有备课桌版上调整公共工作区、工作台、课程选择和移动端布局。保留经典紫橙、银蓝学院与原版界面切换。

## 访问

- 应用：http://127.0.0.1:5188/
- 后端健康检查：http://127.0.0.1:5001/api/health
- 无需登录的开发验收页面：http://127.0.0.1:5188/tests/model-pages-browser.html?page=/dashboard

验收页面使用内存中的模拟身份与数据，阻止接口写入和真实设备采集；不属于正式产品入口，也不包含在 Vite 生产入口中。本轮没有更新公网服务器。

## 交付内容

- 公共工作区：固定导航轨道、导航图标、独立内容滚动、统一间距与焦点样式。外观设置收进可用 Escape 关闭的菜单；账户菜单支持 Escape 返回焦点，小屏增加退出入口。
- 工作台：调整课堂主卡片、快捷入口和反馈区域的比例。新账号也能通过静态导航进入课程与资料；训练记录与评分仍来自真实接口。加载失败显示重试，不显示成功空状态；问候使用当前用户姓名。
- 课程：标题、搜索和课程目录与顶栏分行；桌面保留物件式备课桌，小屏使用桌面插画加教学技能按钮，避免标签互相覆盖。
- 课堂：修复小屏学生席位与连接状态栏重叠；默认与对话布局都允许内容自然滚动。保留原有课堂、录制、设备授权与计时逻辑。
- 助手：手机默认位置移至右下方，避免遮挡账户按钮，继续支持拖动。
- 登录：使用关联到表单的提交按钮，支持输入框中 Enter 提交；注册密码使用 new-password 自动填充语义；角色按钮暴露选中状态。
- 知识库：区分加载中、加载失败与空列表；连接和列表失败支持重试；预览及删除失败显示错误；操作处理中禁用重复操作；窄屏表格可独立横向滚动。
- 备课桌版不再挂载工作区的背景视频、Aurora 和环境动效。原版仍保留原有视觉效果；本轮未测量性能增益。

主要公共样式位于 `frontend/src/themes/workspace.css`，配色以紫灰底色、淡紫面板、暖金强调为主，银蓝版本有对应的浅色变量；像素角色和备课桌作为主要视觉元素。
