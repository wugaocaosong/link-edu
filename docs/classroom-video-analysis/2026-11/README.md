# LINK 课堂视频分析结果（2026-11）

本目录提供 8 段已分析试讲视频的索引、报告和结构化摘要，方便团队查阅。

## 原始分析产物

完整的动作时间戳、声学窗口、逐秒面部输出和模型处理回放位于项目本机：

- `../../../output/mm-tba/<视频名>-analysis-gpu/`：动作事件 JSON/CSV、类别统计、标注回放。
- `../../../output/classroom-audio/<视频名>/`：本地声学特征 JSON。
- `../../../output/facial-analysis/<视频名>/`：人脸跟踪、LibreFace 原始输出和 1 fps 裁切回放。
- `../../../output/classroom-analysis/<视频名>/`：逐视频摘要与报告。

`output/` 按项目 `.gitignore` 规则属于本地数据目录；完整视频衍生文件没有复制进 Git 文档目录。原始视频保留在 `信息科技试讲视频（待收集）` 文件夹。

## 分析范围

- 动作：MM-TBA SlowFast ACRN 推理；记录类别、时间戳和置信度。
- 面部：YuNet 每秒检测和 LibreFace CUDA 原始输出。
- 声学：每 0.2 秒 RMS 音量与过零率；没有运行 ASR、教学话语识别或中文声音情绪模型。

模型输出需要人工回放核验。面部类别/AU、动作标签、声学特征均不是教师真实情绪或教学质量评分。
