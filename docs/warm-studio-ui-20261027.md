# 暖光像素 UI 升级 · 2026-10-27

本轮把已确认的六张效果图落实到现有 Vue 页面：工作台继续训练、成长档案、资源库、个人中心、设置、帮助与反馈。默认备课桌版采用新版布局；原版界面和银蓝主题仍可在外观菜单中切换。没有修改后端接口、训练记录或评分逻辑，没有发布公网版本。

## 页面和行为

- 工作台：真实训练卡加入暖光课堂背景和现有三名学生角色，保留课程、状态、进度与上次训练时间，主按钮改为醒目的整行按钮。
- 成长档案：空评分引导、真实得分曲线、周一开始的月份日历和当日摘要。月份来自接口已提供的数据，未覆盖日期不可选择，不伪造零次记录；月份切换清除旧日期筛选；加载范围竞争只接受最新响应。历史规则评分来源和模拟课堂复练仍保留。
- 资源库：精选资料与课程资源统一卡片布局，增加资料搜索和每页六项的分页；保留分类、真实文件链接、阅读器、下载、失败重试及空结果提示。课程资源总数取自接口，不再显示精选资料数量。分页居中，避开助手。
- 个人中心：身份横幅、真实等级和徽章、资料表单与最近训练。未获得的徽章使用灰色图标；保存处理中禁用重复提交，资料加载失败可重试并禁止覆盖保存。
- 设置：主题预览、使用引导、问候语选择、账号和数据偏好。保留浏览器偏好持久化和恢复默认逻辑。
- 帮助与反馈：双栏留言工作台，操作名为“保存留言”，明确仍写入原有训练日志。空内容校验、保存中状态、失败保留草稿、成功清空草稿。

## 实现与素材

- 新的主题样式为 `frontend/src/themes/warm-studio.css`，限定在 `data-ui-version="studio"`，沿用现有主题与版本状态。主要配色：深紫 `#17131f`、面板 `#211b2c`、浅紫 `#d8b4f0`、暖金 `#ffc278`、正文 `#f6f0fc`。
- 横幅和封面/徽章分别使用可复用的 `StudioBanner`、`StudioArt` 组件；姓名、数据、表单和按钮均为真实 DOM，未使用整页截图代替界面。
- 内置 image_gen 生成的四份独立素材保存于 `frontend/public/assets/warm-studio/`：`classroom.png`、`study.png`、`covers.png`、`badges.png`。封面和徽章采用 3×2 图集，复用下载缓存；完整提示词和参考图文件名见同目录 `provenance.json`。PNG 合计约 7.9 MB，按使用页面加载。
- 前一轮已有修改保持原样。本轮没有初始化 CodeGraph，也未提交或覆盖工作区内其他改动。
